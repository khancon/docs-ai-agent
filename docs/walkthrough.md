# 90-second walkthrough

1. **0–15 seconds:** Open the workbench. Explain that the public evidence mode works without an API key and does not connect to a cluster.
2. **15–35 seconds:** Select “A Pod keeps crashing.” Open a supporting passage and show its original pinned source.
3. **35–55 seconds:** Start a new investigation and select “Review a deployment.” Show the Service selector mismatch and distinguish static findings from cluster diagnosis.
4. **55–70 seconds:** Expand retrieval activity; show the strategy, request ID, duration and corpus revision.
5. **70–90 seconds:** Open Evaluation and How it works. Explain the development-set limitation, offline index, and provider failure fallback.

After inference credentials are configured, record a separate live-generation example and identify its provider/mode. Never present precomputed responses as live generation.
